Sobre o projeto

A primeira versão deste site foi desenvolvida por mim há algum tempo, utilizando exclusivamente HTML, CSS e JavaScript puros.

Posteriormente, realizei um refinamento do projeto com o objetivo de avaliar as capacidades do Claude em sua versão gratuita. Este repositório contém o resultado desse trabalho.

O site encontra-se atualmente em uso: [docehica.pages.dev](https://docehica.pages.dev/).
